3. ゴールデンウィーク 1泊2日プラン案

soft plan
DAY 1 · 午後到着想定
移動 → 現地チェック → 海岸散歩 → 夕方キャンプムード
  • 昼食後に移動して、早朝出発の負担を減らす
  • 祝日利用条件なら当日受付を先に確認
  • サイトを確保してから海岸散歩で景色を見る
  • 夕景の写真、軽いコーヒーやおやつ、夕食準備
  • 夜は風と体感温度を見て装備を調整
DAY 2 · 朝の景色中心
朝の海を見る → ブランチ → 片付け → 近場ドライブ
  • 少し早起きして海側の空気を先に楽しむ
  • 軽いブランチのあと撤収準備
  • ごみ持ち帰り前提で片付け動線を単純化
  • チェック後に雨晴海岸の写真スポットへ少し立ち寄る

4. 先に確認すること

priority
ゴールデンウィーク = 祝日シーズン
公式案内では、金・土・日・祝日と7〜8月の利用時は 利用当日に WaveLunch で受付が必要です。
営業期間はシーズン内
4月1日〜11月30日営業なので、ゴールデンウィークは営業期間内です。
ごみ捨て場なし
公式案内どおり、ごみは必ず持ち帰る前提で準備が必要です。
基本設備あり
トイレ、冷水シャワー、炊事場の案内が確認できます。
料金メモ 公式案内では、金・土・日・祝日および7〜8月は 管理協力費が1グループ1日1,000円 / 1泊2,000円です。
